# BmCodex Telethon Userbot

Userbot Telegram berbasis **Telethon**, siap deploy dengan mudah melalui Heroku.

---

## 🚀 Deploy ke Heroku

Klik tombol berikut untuk melakukan deploy otomatis:

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/bimazainudinikhsan/BmCodex)

---

## 📦 Fitur Utama
- Autoreply
- Autojoin & autoresponder
- Manajemen grup
- Anti-spam
- Logging lengkap
- Modular (mudah ditambah command baru)

---

## 🛠 Cara Manual Deploy
1. Clone repository:
   ```
   git clone https://github.com/bimazainudinikhsan/BmCodex
   ```
2. Install requirements:
   ```
   pip install -r requirements.txt
   ```
3. Jalankan userbot:
   ```
   python3 main.py
   ```

---

## 🔑 Environment Variables (Heroku)
Pastikan mengisi:
- `API_ID`
- `API_HASH`
- `SESSION_STRING`
